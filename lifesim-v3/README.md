# 人生模拟器 v3 · 出生到死亡

县域青年视角，从 0 岁出生走到死亡。纯静态网页，双击 `index.html` 或通过链接打开。

## 一、这一版改了什么

| 变化 | 说明 |
| --- | --- |
| 起点 | 出生（0 岁），不再从 30 岁截断 |
| 终点 | 死亡，分三类：**寿终正寝 / 疾病死亡 / 意外死亡** |
| 死亡时间 | 由年龄、健康、叛逆、职业风险逐年计算，不是固定值 |
| 人生节点 | 14 个大事件（7/11/13/15/18/22/27/30/33/36/45/52/58/70 岁） |
| 选项 | 每个节点 3—5 个系统选项 + **「其他」自定义输入** |
| 属性 | 十维：健康、学业、情绪、叛逆、家庭、社交、财富、职业、自主、运气 |
| 叛逆子系统 | 10—18 岁每年累积，家庭支持高 → 转化为自主；家庭支持低 → 情绪受损 |
| 评价 | 财富、健康、亲密关系、自主、家庭支持、晚年质量、遗憾，加总评级 S/A/B/C/D |

## 二、死亡模型（可调）

每年结束时做一次判定，三类风险同时存在：

```
自然死亡 = 年龄基准概率 × (1.7 − 健康/90)
疾病死亡 = 0.0002 + max(0, 40−健康)×0.00025 + (年龄≥55 起每年递增)
意外死亡 = 0.001 + 青少年叛逆修正 + 高龄修正 + 灵活就业修正
```

- 年龄基准概率在 `data.js` 的 `NATURAL_MORTALITY`，按 35/50/60/70/75/80/85/90/95/100 分段插值。
- 健康 ≤ 0 时：85 岁以上算寿终正寝，以下算疾病。
- 想调「平均活多久」「疾病多不多」「意外多不多」，只改这两处，不用动逻辑。

**当前校准结果**（5000 局随机人生）：

| 指标 | 数值 |
| --- | --- |
| 平均寿命 | 75.2 岁（中位数 81，p10 57，p90 88） |
| 寿终正寝 | 59.1% |
| 疾病死亡 | 30.4% |
| 意外死亡 | 10.5% |

## 三、人生节点

| 年龄 | 节点 | 系统选项 |
| --- | --- | --- |
| 7 | 入学 | 全力投入 / 普通陪伴 / 放养 |
| 11 | 青春期萌芽 | 高压控制 / 放任 / 引导式自主 |
| 13 | 手机被没收 | 顶撞 / 沟通 / 隐忍 |
| 15 | 中考 | 冲刺普高 / 中职学技术 / 打工 |
| 18 | 高考 | 本科 / 专科 / 职教高考 / 就业 / 复读 |
| 22 | 毕业 | 读研 / 考公 / 大城市 / 灵活就业 / 待业 |
| 27 | 婚恋 | 结婚 / 再等 / 不婚 |
| 30 | 要不要孩子 | 现在要 / 再等 / 丁克 / 想要但困难 |
| 33 | 买房 | 一线 / 二三线 / 租房 / 不买 |
| 36 | 三十五六 | 跳槽 / 留守 / 转行 / 考编 |
| 45 | 中年路口 | 管理岗 / 技术纵深 / 顾家 / 创业 |
| 52 | 空巢 | 重新规划 / 照顾老人 / 照旧 / 二次创业 |
| 58 | 退休 | 法定 / 提前 / 灵活 / 返聘 |
| 70 | 晚年安排 | 与子女 / 独居 / 机构 / 社区旅居 |

每个节点底部都有「其他」输入框：写一句你想做的事（40 字内），系统按关键词归类（学习 / 打工 / 创业 / 婚恋 / 生育 / 买房 / 休息 / 离开 / 其他），走一次判定并结算，效果受 ±上限约束。

## 四、文件结构

```
人生模拟器-v3/
├── index.html      五个屏幕：标题 / 出生 / 人生 / 死亡 / 设置
├── css/style.css   深色主题 + 节点卡 + 评分条
└── js/
    ├── data.js     十维属性、14 个节点、20 个随机事件、死亡表、结局
    ├── engine.js   时间轴、叛逆子系统、判定、死亡、多维评价
    ├── storage.js  存档（v3 独立键名）
    └── ui.js       渲染、节点卡、自定义输入、死亡页
```
